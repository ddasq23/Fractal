# Fractal v0.1-beta

The first public beta of **Fractal**, a Wii U emulator for Android handhelds and phones, forked from Cemu and tuned
for Adreno and Mali GPUs.

> **This is a beta.** Many games run, many don't yet, and results change from one device or GPU driver to another. Back
> up your saves and report what you find.

## Highlights

- New interface made for gamepads: five themes (Solid, Liquid Glass, Blur, Material You, Synthwave), static and animated
  wallpapers, a game library with grid, carousel and list views, play time and per-game settings.
- **Resolution & FPS** options per game, detected from the community graphic packs.
- GPU drivers page: install Turnip builds for Adreno (and experimental Mali drivers) in one tap, globally or per game,
  with automatic fallback to the system driver.
- Vulkan renderer tuned for tile-based mobile GPUs and a faster ARM64 recompiler.
- On-screen controls with profiles, macros and turbo; automatic mapping for physical controllers; hotkeys; in-game menu.
- AMD FSR 1 and Snapdragon GSR upscaling.
- Built-in debug report (**Options › Share debug report**).
- English, Português (Brasil) and Español.
- **New in the updated build (2026-11-15, version code 2):** GamePad screen on a second display (AYN Thor bottom screen,
  external monitor) with touch, its own scaling and size; **frame generation** with your own Lossless Scaling
  `Lossless.dll` (2x/3x/4x or adaptive to 60/90/120 FPS), imported and tuned from the settings or the in-game menu; the
  back button opens the in-game menu on the AYN Odin 3; fewer Assassin's Creed IV jungle blackouts (recompiler `fsel`).

## Game fixes

Fixed in code shared with the PC version of Cemu: **The Amazing Spider-Man** now shows a picture, **Watch Dogs** no
longer crashes at boot or in gameplay and no longer freezes from the prologue, **Injustice** no longer hangs the GPU,
**Need for Speed: Most Wanted U** engine sound no longer pops, and shaders precompiled at boot are no longer compiled
again in game.

Fixed for Android GPUs, drivers and ARM64: **Ninja Gaiden 3: Razor's Edge**, **Tekken Tag Tournament 2**,
**Assassin's Creed IV**, **Xenoblade Chronicles X**, **Bayonetta 2**, **Pokkén Tournament**, **Breath of the Wild**,
**Star Fox Zero**, **Mario Kart 8** and more.

Full list with the commit behind each fix: [roadmap](https://github.com/dfdx047/Fractal/blob/main/docs/ROADMAP.md) ·
[changelog](https://github.com/dfdx047/Fractal/blob/main/CHANGELOG.md).

## Requirements

- Android 11 or newer, 64-bit ARM (arm64-v8a), a Vulkan 1.1 GPU.
- Main target: Adreno 6xx/7xx. Mali works with more issues.
- Tested on Retroid Pocket 5 (Snapdragon 865), Anbernic RG Cube (Mali-G57), Xiaomi Mi A3 (Snapdragon 665), AYN Odin 2
  Mini (Snapdragon 8 Gen 2), AYN Odin 3 (Snapdragon 8 Elite) and AYN Thor (Snapdragon 8 Gen 2, dual screen).
- Frame generation needs a driver with the Vulkan memory model, float16 and null descriptors; the in-game menu shows its
  status.

## Install

Download the APK below, install it and follow the welcome setup. Fractal does not include or download games, keys or
firmware: use dumps of games you own. Decrypted games (.wua) need no keys.

## Known issues

- **Assassin's Creed IV:** in the jungle (finding the Assassin, near the bridge and the waterfall) the world can turn
  black with only the HUD left. Much rarer since the `fsel` fix, still not gone. Also on PC.
- **Watch Dogs:** on Turnip the GPU can hang after about 25 minutes (use the system driver for long sessions); on Mali
  (RG Cube) it gets stuck compiling shaders. On Android the picture can turn overexposed (too bright, but with detail) from
  the Maurice room on and stay that way; it happens in about half of the sessions on both Adreno drivers.
- **Ninja Gaiden 3 on Turnip:** dark floating heads and a blown-out sky in some scenes.
- **Xenoblade Chronicles X on the Qualcomm system driver:** characters drawn as white silhouettes; use Turnip.
- **Need for Speed: Most Wanted U:** white foliage without the Bloom Fix graphic pack (on by default).
- **Mali GPUs:** less tested and slower; custom Mali drivers are experimental.
- Android has no immediate present mode: VSync off behaves like double buffering.

## Reporting bugs

Open **Options › Share debug report** after the problem happens and attach `debug_report.zip` to a
[new issue](https://github.com/dfdx047/Fractal/issues/new/choose), with your device, GPU driver and the game's Title ID.
Please do not report Fractal bugs to the Cemu team.

- O Android não tem modo de apresentação imediato: VSync desligado funciona como buffer duplo.
